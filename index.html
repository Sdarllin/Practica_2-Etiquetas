Diccionario Académico: 102 Etiquetas HTML

Listado completo de etiquetas HTML estandarizadas con su descripción, sintaxis de ejemplo y observaciones técnicas adicionales.

Tabla de referencia general de etiquetas HTML
# Nombre de la Etiqueta Descripción Ejemplo de Uso Elemento Adicional
1 <!-- --> Incrusta comentarios en el código fuente que el navegador no renderiza. <!-- Esto es un comentario --> Útil para documentar la estructura del código.
2 <!DOCTYPE> Declara el tipo de documento y la versión de HTML empleada. <!DOCTYPE html> Debe ser la primera línea del documento HTML5.
3 <a> Define un hipervínculo para enlazar otros recursos o páginas. <a href="https://example.com">Enlace</a> El atributo target="_blank" abre el enlace en una pestaña nueva.
4 <abbr> Muestra una abreviatura o acrónimo y su significado completo. <abbr title="Organización de las Naciones Unidas">ONU</abbr> Al pasar el ratón, el atributo title muestra el texto completo.
5 <address> Proporciona información de contacto del autor o propietario del documento. <address>Contacto: correo@dominio.com</address> Por defecto, se renderiza visualmente en texto cursivo.
6 <area> Define un área con hipervínculo dentro de un mapa de imagen. <area shape="rect" coords="0,0,50,50" href="pagina.html" alt="Área"> Elemento vacío asociado a una etiqueta <map>.
7 <article> Representa una composición autónoma y reutilizable en el documento. <article><h2>Noticia</h2><p>Detalle...</p></article> Ideal para entradas de blog, noticias o artículos de opinión.
8 <aside> Contiene contenido secundario o indirectamente relacionado con el texto principal. <aside><p>Enlace relacionado</p></aside> Utilizado frecuentemente para barras laterales o barras de navegación secundaria.
9 <audio> Incrusta contenido de audio o reproductor de sonido en la página. <audio src="audio.mp3" controls></audio> El atributo controls habilita los botones de reproducción del navegador.
10 <b> Resalta texto para llamar la atención sin implicar mayor importancia semántica. <b>Texto destacado</b> Para énfasis de importancia semántica se prefiere usar <strong>.
11 <base> Especifica la URL base y el objetivo predeterminado para todos los enlaces relativos. <base href="https://example.com/dir/" target="_blank"> Se coloca exclusivamente dentro de la sección <head>.
12 <bdi> Aísla una parte de texto que puede formatearse en una dirección diferente a la del entorno. <bdi>اسم User</bdi> Útil al incrustar nombres o contenidos con escritura bidireccional (p. ej. árabe/hebreo).
13 <bdo> Anula la dirección del texto actual y fuerza la orientación especificada. <bdo dir="rtl">Texto al revés</bdo> Requiere obligatoriamente el atributo dir (ltr o rtl).
14 <blockquote> Indica una cita textual de una fuente externa extensa. <blockquote cite="https://fuente.com">Cita externa</blockquote> El atributo cite permite enlazar la URL original del texto citado.
15 <body> Contiene todo el contenido visible de un documento HTML. <body><p>Contenido principal</p></body> Solo debe haber un único elemento <body> por documento.
16 <br> Produce un salto de línea dentro de un bloque de texto. Línea 1<br>Línea 2 Es una etiqueta vacía (no requiere etiqueta de cierre).
17 <button> Crea un botón interactivo dentro de un formulario o la interfaz. <button type="button">Enviar</button> Tipos comunes: submit, reset y button.
18 <canvas> Proporciona un lienzo gráfico dibujable mediante scripts (JavaScript). <canvas id="lienzo" width="200" height="100"></canvas> Utilizado ampliamente para videojuegos web y renderizado 2D/3D.
19 <caption> Define un título o descripción explícita para una tabla. <table><caption>Tabla 1.1</caption>...</table> Debe ser el primer elemento secundario insertado dentro de una <table>.
20 <cite> Define el título de una obra (libro, canción, película, estudio). <cite>Don Quijote de la Mancha</cite> Se renderiza habitualmente en cursiva.
21 <code> Muestra un fragmento de código de computadora o sintaxis de programación. <code>console.log("Hola");</code> Se muestra predeterminadamente con una tipografía de ancho fijo (monoespaciada).
22 <col> Especifica propiedades comunes para columnas individuales dentro de un <colgroup>. <colgroup><col span="2"></colgroup> Simplifica el formateo en bloque de tablas sin repetir atributos por celda.
23 <colgroup> Agrupa una o más columnas dentro de una tabla para formatearlas de forma unificada. <colgroup><col><col></colgroup> Debe ubicarse dentro de <table> antes de <thead> y <tbody>.
24 <data> Enlaza un contenido dado con un valor legible por máquina. <data value="101">Producto Cien</data> Facilita el procesamiento estructurado por scripts de backend o algoritmos.
25 <datalist> Especifica una lista de opciones prediseñadas para un elemento <input>. <datalist id="colores"><option value="Rojo"></datalist> Se vincula a la casilla mediante el atributo list en el <input>.
26 <dd> Proporciona la descripción o valor de un término en una lista de descripción (<dl>). <dd>Texto descriptivo del término</dd> Se utiliza siempre en combinación con la etiqueta <dt>.
27 <del> Muestra texto que ha sido eliminado o modificado en un documento. <del>Texto tachado antiguo</del> Aparece visualmente renderizado con un tachado en el centro.
28 <details> Crea un desplegable desplegable que el usuario puede abrir y cerrar. <details><summary>Ver más</summary><p>Detalle...</p></details> Muestra información oculta bajo un botón desplegable sin depender de JavaScript.
29 <dfn> Indica el término que se está definiendo formalmente en el texto adyacente. <dfn>HTML</dfn> es un lenguaje de marcado... Generalmente se visualiza en texto itálico.
30 <dialog> Define una caja de diálogo, ventana emergente o modal dentro de la página. <dialog open><p>Ventana Abierta</p></dialog> El atributo open la hace visible por defecto en pantalla.
31 <div> Define una división o contenedor de bloque genérico. <div><p>Contenido agrupado</p></div> Elemento neutro sin significado semántico por sí mismo.
32 <dl> Define una lista de descripción de pares de términos y definiciones. <dl><dt>Término</dt><dd>Definición</dd></dl> Utilizado en glosarios, diccionarios y listas de atributos de productos.
33 <dt> Especifica el término clave que será definido dentro de una lista de descripción (<dl>). <dt>Concepto</dt> Procede directamente antes de la etiqueta de descripción <dd>.
34 <em> Enfatiza texto, alterando el tono verbal de lectura del mismo. <em>Texto enfatizado</em> Por norma general, los navegadores lo muestran formateado en cursiva.
35 <embed> Actúa como contenedor para recursos o aplicaciones externas multimedia. <embed type="image/jpg" src="imagen.jpg" width="300" height="200"> Etiqueta vacía; se recomienda usar <object> o <iframe> en su lugar.
36 <fieldset> Agrupa visual y semánticamente controles o campos relacionados dentro de un formulario. <fieldset><legend>Datos</legend></fieldset> Se acompaña habitualmente de la etiqueta <legend> para asignarle un título.
37 <figcaption> Proporciona una leyenda descriptiva para un elemento de figura (<figure>). <figure><img src="f.jpg" alt="A"><figcaption>Leyenda</figcaption></figure> Aporta coherencia semántica en gráficos e ilustraciones.
38 <figure> Contenido autónomo como ilustraciones, diagramas, fotos o bloques de código. <figure><img src="foto.jpg" alt="Ilustración"></figure> Mantiene desacoplada la figura del flujo principal de texto.
39 <footer> Representa el pie de página o la sección de cierre de un documento o sección. <footer><p>Derechos reservados</p></footer> Suele contener información de derechos de autor y enlaces legales.
40 <form> Crea un formulario interactivo para la recolección y envío de datos del usuario. <form action="/enviar" method="post">...</form> Atributos clave: action (destino) y method (GET/POST).
41 <h1> Define el encabezado o título de nivel principal y mayor jerarquía. <h1>Título Principal</h1> Se recomienda mantener únicamente un nivel h1 por página por SEO.
42 <h2> Define un encabezado de nivel secundario. <h2>Subtítulo de Sección</h2> Estructura el contenido dentro del bloque principal.
43 <h3> Define un encabezado de tercer nivel jerárquico. <h3>Subsección</h3> Útil para agrupar temáticas menores dentro de un nivel h2.
44 <h4> Define un encabezado de cuarto nivel. <h4>Tema Secundario</h4> Aumenta la especificidad de las subdivisiones del texto.
45 <h5> Define un encabezado de quinto nivel. <h5>Título Menor</h5> Raramente utilizado en esquemas de contenidos reducidos.
46 <h6> Define el encabezado de menor jerarquía disponible en HTML. <h6>Detalle Mínimo</h6> Último nivel jerárquico antes de bloques de párrafo simple.
47 <head> Contenedor de metadatos, títulos, enlaces a scripts y hojas de estilo. <head><title>Mi Sitio</title></head> No es visible directamente en el cuerpo renderizado de la página.
48 <header> Representa la cabecera o bloque introductorio de un documento o sección. <header><h1>Encabezado del Sitio</h1></header> Suele contener barras de navegación principales e logotipos corporativos.
49 <hgroup> Agrupa un conjunto de encabezados relacionados (<h1>-<h6>). <hgroup><h1>Título</h1><h2>Subtítulo</h2></hgroup> Optimiza la lectura jerárquica para lectores de pantalla.
50 <hr> Representa una ruptura temática o separación de párrafo. <p>Tema 1</p><hr><p>Tema 2</p> Suele renderizarse como una línea horizontal divisoria.
51 <html> Representa la raíz de todo el documento HTML. <html lang="es">...</html> El atributo lang indica el idioma oficial del documento.
52 <i> Formatea texto en una voz o tono alternativo (términos técnicos, nombres de barcos). <i>Homo sapiens</i> Frecuentemente utilizado en la presentación de términos extranjeros o científicos.
53 <iframe> Incrusta un documento HTML completo o sitio web secundario en la página actual. <iframe src="https://example.com" title="Marco"></iframe> Requiere el atributo title para garantizar accesibilidad web.
54 <img> Incrusta un archivo de imagen en la página web. <img src="imagen.jpg" alt="Descripción de la imagen"> El atributo alt es fundamental para la accesibilidad y el SEO.
55 <input> Crea un campo interactivo de entrada de datos en un formulario. <input type="text" name="usuario" placeholder="Nombre"> Soporta múltiples tipos: text, password, checkbox, radio, file, entre otros.
56 <ins> Muestra texto que ha sido añadido formalmente a un documento. <ins>Texto agregado recientemente</ins> Por defecto se presenta con un subrayado inferior.
57 <kbd> Representa entradas de teclado, voz o acciones manuales del usuario. Presione <kbd>Ctrl</kbd> + <kbd>C</kbd> Aparece con una tipografía monoespaciada en pantalla.
58 <label> Representa una etiqueta explicativa vinculada a un control de formulario. <label for="nombre">Nombre:</label> El atributo for debe coincidir con el id del campo asociado.
59 <legend> Representa el título descriptivo para el contenido de un <fieldset>. <legend>Información Personal</legend> Debe ubicarse inmediatamente después de la apertura de <fieldset>.
60 <li> Define un elemento individual perteneciente a una lista. <li>Elemento de lista</li> Debe estar contenido dentro de etiquetas <ul>, <ol> o <menu>.
61 <link> Establece enlaces a recursos externos (hojas de estilo, favicons). <link rel="stylesheet" href="estilo.css"> Ubicado exclusivamente dentro del encabezado de página <head>.
62 <main> Encierra el contenido central y dominante del cuerpo del documento. <main><p>Contenido único</p></main> Solo debe haber un elemento <main> visible por página.
63 <map> Define un mapa de imágenes interactivo con áreas cliqueables. <map name="mapa"><area ...></map> Se enlaza con la etiqueta <img> mediante el atributo usemap.
64 <mark> Representa texto resaltado para propósitos de referencia o relevancia actual. <mark>Texto resaltado</mark> Por defecto se presenta con un fondo amarillo en los navegadores.
65 <menu> Semánticamente representa una lista no ordenada de elementos de menú o comandos. <menu><li>Opción 1</li></menu> Funciona alternativamente como un alias semántico para la etiqueta <ul>.
66 <meta> Suministra metadatos estructurados sobre el documento (codificación, autor, viewport). <meta charset="UTF-8"> Crucial para el diseño web adaptativo (responsive) y la optimización SEO.
67 <meter> Muestra una medida escalar dentro de un rango numérico conocido. <meter value="0.6" min="0" max="1">60%</meter> Útil para representar uso de disco, batería o porcentajes cerrados.
68 <nav> Contiene enlaces principales orientados a la navegación por el sitio. <nav><a href="/">Inicio</a></nav> Ayuda a los motores de búsqueda a identificar los menús clave.
69 <noscript> Muestra un contenido alternativo si el navegador carece de soporte para JavaScript. <noscript>JavaScript está desactivado.</noscript> Aparece en pantalla únicamente cuando los scripts están inactivos.
70 <object> Representa un recurso externo ejecutable (imágenes, PDF, plugins). <object data="archivo.pdf" type="application/pdf"></object> Permite incluir contenido alternativo dentro si el recurso falla.
71 <ol> Define una lista de elementos estructurada de forma ordenada y numerada. <ol><li>Paso 1</li></ol> El atributo type permite cambiar el estilo numérico (letras, números romanos).
72 <optgroup> Crea una agrupación de opciones asociadas dentro de un menú desplegable (<select>). <optgroup label="Frutas"><option>Manzana</option></optgroup> El atributo label define el nombre del bloque agrupado.
73 <option> Define un elemento o alternativa dentro de una lista <select> o <datalist>. <option value="1">Opción 1</option> El atributo value se envía al servidor al procesar el formulario.
74 <output> Representa el resultado directo de un cálculo o interacción en un formulario. <output name="resultado">100</output> Suele vincularse a cálculos ejecutados mediante JavaScript.
75 <p> Define un párrafo de texto autónomo dentro del cuerpo. <p>Este es un párrafo explícito.</p> Inserta un margen vertical automático encima y debajo del bloque.
76 <picture> Contenedor flexible para ofrecer distintas imágenes según resoluciones o dispositivos. <picture><source srcset="i.webp"><img src="i.jpg" alt="A"></picture> Optimiza la carga adaptativa de imágenes para dispositivos móviles.
77 <pre> Representa texto preformateado respetando los espacios en blanco y saltos de línea. <pre> Texto Formateado </pre> Mantiene fielmente los tabuladores ingresados en el código fuente.
78 <progress> Muestra una barra de progreso que indica el avance de una tarea. <progress value="70" max="100">70%</progress> Proporciona una interfaz estándar nativa de nivel de avance.
79 <q> Indica una cita textual corta intercalada dentro de la misma línea de texto. El autor dijo: <q>Hola mundo</q> Los navegadores añaden automáticamente comillas alrededor del texto.
80 <rp> Suministra caracteres entre paréntesis para navegadores sin soporte para anotaciones ruby. <ruby>漢 <rp>(</rp><rt>Kan</rt><rp>)</rp></ruby> Complementa la accesibilidad tipográfica asiática.
81 <rt> Muestra la anotación de pronunciación o explicación sobre los caracteres dentro de <ruby>. <ruby>漢 <rt>Kan</rt></ruby> Utilizado primordialmente en la lectura de caracteres de Asia Oriental.
82 <ruby> Representa pequeñas anotaciones sobre el texto principal, comunes en idiomas de Asia Oriental. <ruby>漢 <rt>Kan</rt></ruby> Agrupa los elementos internos de fonética <rt> y fallbacks <rp>.
83 <s> Muestra texto que ya no es preciso o relevante, presentándolo tachado. <s>Precio antiguo: $50</s> A diferencia de <del>, no implica una edición editorial explícita.
84 <samp> Muestra salidas o respuestas directas generadas por un programa de computadora. Respuesta del sistema: <samp>Error 404</samp> Renderiza el contenido mediante una fuente tipográfica monoespaciada.
85 <script> Incrusta o enlaza scripts ejecutables en el cliente (JavaScript). <script src="script.js"></script> Los atributos async y defer gestionan la carga asíncrona del script.
86 <section> Define una sección genérica y semántica de contenido temático agrupado. <section><h2>Tema</h2><p>Detalle</p></section> Debería incluir habitualmente una etiqueta de encabezado (<h1>-<h6>).
87 <select> Crea una lista desplegable interactiva de selección dentro de un formulario. <select name="opcion"><option>A</option></select> El atributo multiple permite elegir más de una opción simultáneamente.
88 <small> Representa comentarios laterales, exenciones de responsabilidad o letra pequeña. <small>Términos y condiciones aplican.</small> Visualmente muestra el texto con un tamaño de fuente reducido.
89 <source> Especifica múltiples recursos de medios para elementos <picture>, <video> o <audio>. <source src="video.mp4" type="video/mp4"> Permite entregar el formato óptimo soportado por el navegador.
90 <span> Contenedor en línea neutro sin significado semántico nativo. <span>Texto aislado</span> Usado comúnmente para aplicar reglas de estilo o manipular texto en JS.
91 <strong> Indica que el contenido interno posee una importancia, seriedad o urgencia alta. <strong>¡Atención importante!</strong> Los navegadores muestran visualmente el contenido en negrita.
92 <style> Contiene instrucciones de estilo CSS aplicables al documento actual. <style>p { color: blue; }</style> Se coloca habitualmente dentro del encabezado <head>.
93 <sub> Define un texto formateado en posición de subíndice. Fórmula del agua: H<sub>2</sub>O Reduce la tipografía y la desplaza ligeramente hacia abajo.
94 <summary> Define el encabezado visible del contenedor desplegable <details>. <details><summary>Más datos</summary></details> Hace las funciones de botón para expandir o contraer la sección.
95 <sup> Define un texto formateado en posición de superíndice. Ecuación: E = mc<sup>2</sup> Reduce la tipografía y la desplaza hacia la parte superior.
96 <table> Crea y delimita una tabla de datos bidimensional (filas y columnas). <table><tr><td>Celda</td></tr></table> Debe contener etiquetas internas estructuradas como <tr>, <td> y <th>.
97 <tbody> Agrupa el bloque con el contenido principal o cuerpo de datos de una tabla. <tbody><tr><td>Datos</td></tr></tbody> Complementa la estructura junto con las secciones <thead> y <tfoot>.
98 <td> Define una celda estándar contenedora de datos dentro de una fila de tabla. <tr><td>Dato Celda</td></tr> Los atributos colspan y rowspan permiten expandir celdas.
99 <template> Contenedor de código HTML que no se renderiza en la carga, pero puede ser instanciado en JS. <template id="mi-plantilla"><p>Texto</p></template> Fundamental en el desarrollo de componentes web dinámicos.
100 <textarea> Crea un campo de entrada de texto multilínea de tamaño ajustable. <textarea rows="4" cols="50">Escriba aquí...</textarea> Los atributos rows y cols controlan su dimensión inicial predeterminada.
101 <tfoot> Agrupa la sección de cierre o resumen al final de una tabla de datos. <tfoot><tr><td>Total</td></tr></tfoot> Útil para filas de sumatorias o promedios.
102 <th> Define una celda de encabezado descriptivo dentro de una fila de tabla. <tr><th>Encabezado Columna</th></tr> El atributo scope="col" o "row" aclara la dirección que encabeza.
